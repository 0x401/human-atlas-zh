# Human Atlas（人体图谱）

一个基于 React、Three.js 与 shadcn/ui 构建的交互式 3D 人体解剖浏览器。以 BodyParts3D 成年男性参考模型为基础，可拆解为 **2,234 个可单独选择的网格**，覆盖 **15 个解剖系统**，并支持检索 **3,432 个命名概念**。

**[在线体验 Demo](https://human-atlas-zh.vercel.app/)**

[English](README.md) | 简体中文

## 浏览功能

- 直接在人体上旋转、缩放并选择结构。
- 单独开关各个系统，或使用骨骼、器官预设。
- 从完整人体切换到所有可见部件的分散排布清单。
- 搜索解剖学名称与来源标识符。
- 隔离选中的结构并查看其详细信息。
- 移动端提供紧凑的控制条与详情面板。

## 本地运行

需要 Node.js 22.13 或更高版本，无需 API 密钥或账号。

```sh
npm ci
npm run dev
```

打开 http://localhost:3016。若要构建静态站点，执行 `npm run build`，产物位于 `dist/`。

## 校验

```sh
npm run check
node scripts/validate-atlas.mjs
node scripts/validate-interactions.mjs
npm run build
```

校验范围包括：网格缓冲区、名称与概念归属、桌面端与移动端宽高比下分散布局不重叠、搜索与查看的契约、以及点击与拖拽的区分处理。浏览器交互检查已覆盖选择、系统控制、搜索、隔离、旋转，以及 390×844、320×568、844×390 三种布局。手机端控件不会遮挡分散清单，被隔离的结构能够适配详情面板上方或侧边的空间。真机性能与真实多点触控硬件尚未测试。

## 新增语言

英文为内建语言，简体中文位于 `app/languages/zh.ts`。每种语言是一个自包含文件，目录会被自动扫描，因此新增语言不需要改动任何注册表或应用代码。

添加方法：将 `app/languages/zh.ts` 复制为 `app/languages/<code>.ts`（如 `ja.ts`），更新 `meta` 导出（唯一的 `code`、`label`、`nativeName`、`htmlLang`、`title`、`description`），再翻译 `copy`（界面文案）与 `structure`（结构名称，每行行尾注释即规范英文名）中的值。键与结构编号保持不变，未翻译的内容自动回退英文。文件下次加载即自动生效，运行 `npm run check` 校验即可。

## 解剖数据

当前查看器使用 **BodyParts3D 4.0**（成年男性参考解剖数据），授权协议为 **CC BY 4.0**。它并不代表人体的全部结构或变异。单个来源网格与命名概念并不一一对应，一个概念可能包含多个网格。描述文字会区分系统层面的概述与单个器官的说明。

几何体为浏览器性能做了简化，但保留了每一个来源网格。打包后的模型包含 2,288,268 个三角面，压缩后约需下载 33 MB 几何数据。完整的署名信息、来源链接与改编说明见 [ATTRIBUTION.md](public/ATTRIBUTION.md)。

这是一个用于学习的浏览工具，不是诊断或手术工具。

## 实现原理

几何体会合并为批次。每个结构的 GPU 纹理控制其位移、可见性与选中状态，而组件级几何体保证拾取的准确性。分散布局只对可见部件进行排布。渲染在场景变化时更新；轨道控制保持流畅，无需上千次独立绘制调用。

可选的 WebMCP 工具会在兼容的浏览器中开放解剖搜索与查看能力，不启用时界面依然完整可用。

## 重建几何体

仓库中已包含可直接用于浏览器的几何体，重建是可选步骤：获取官方 BodyParts3D OBJ 压缩包与英文元数据表，整理合并后的概念与展示系统映射，依次运行 `scripts/convert-anatomy.py`、`node scripts/optimize-anatomy.mjs` 和 `node scripts/compress-models.mjs`。简化过程对每个结构采用 0.2% 的相对误差上限。

## 部署

在 Vercel 中导入本仓库，选择 Vite 项目类型。附带的 `vercel.json` 已配置 `npm ci`、`npm run build` 以及 `dist` 输出目录。也可以使用任意静态托管服务。
